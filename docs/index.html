physics-arcade benchmark

Can AI predict what happens next?

Three tiny physics games. A model sees the first 0.4 seconds of a shot, before anything collides, and has to call the outcome. So far, vision-language models barely beat a coin flip.

How it works

Fair answer keys

Collisions are chaotic: a launch that differs by 0.25 % in speed can change who survives. Every episode is replayed 50 times under such tiny perturbations, and each target's label is how often its event happens. Scores count only targets with a clear-cut fate.

Difficulty and style

Each game has easy, medium and hard levels, and two render styles with identical physics: flat colors and textured cartoon. All levels come from a physics simulator, so there is no limit on data and the ground truth is exact.

Add your model

The evaluation harness takes any model that maps images and text to a reply. Run it, then score with physics-arcade leaderboard. See the README.
